# Консольное приложения для получения информации о погоде ITKOR

Консольная утилита на Node.js для получения прогноза погоды через Open-Meteo API 
с поддержкой кэширования в JSON-файлы и параллельной обработки нескольких городов.

## Требования
- Node.js 20+

## Установка и запуск
1. Клонировать репозиторий:

    git clone <ссылка_на_репозиторий>
    cd itkor

2. Настроить окружение:
    cp .env.example .env

3. Запустить утилиту:

    npm start -- --city "Екатеринбург, Москва" --days 4

--no-cache - игнорировать сохраненный кэш и сделать прямой запрос к API.

Структура проекта
src/index.js - точка входа
src/cli.js - парсинг и валидация аргументов CLI
src/config.js - конфигурация переменные окружения
src/api/ - работа с Open-Meteo API
src/storage/ - чтение и запись JSON-кэша в reports/
src/format/ - форматирование отчета для вывода
docs/postman/ - коллекция Postman
